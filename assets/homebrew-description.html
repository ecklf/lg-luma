Home Chooser is recommended for using Luma as your Home screen. Install it from Homebrew Channel, open it once, then select Luma.

A native launcher for rooted LG webOS TVs.

  • A favorites dock, animated app drawer with optional app names, app management and Recent apps.
  • Customizable input names and icons.
  • A customizable Home grid with widgets.
  • Uploaded photo backgrounds, gradient shading and automatic rotation.
  • QR-managed webhook shortcuts for automations.
  • In-app updates.

Available in Catalan, Czech, Dutch, English, French, German, Hungarian, Italian, Polish, Portuguese (Brazil), Russian, Simplified / Traditional Chinese, Spanish, Swedish and Vietnamese.
